### 📊 What it does?
Real-time stock analysis app with technical indicators, user authentication, and portfolio tracking. Transforms financial data into live web app.

### 🛠️ Tech Stack (Python Developer Level)
- **Backend:** Python, Flask, Pandas, yFinance API
- **Database:** SQLAlchemy, Flask-Login (SQLite → PostgreSQL ready)
- **Frontend:** Chart.js, HTML5, CSS3
- **DevOps:** Docker, Gunicorn, Render Deployment
- **Analysis:** MA20, MA50, RSI, Daily Returns calculation

### ✨ Features
- ✅ Real-time stock price fetch (NSE & NASDAQ)
- ✅ Technical Analysis with Pandas
- ✅ Interactive Charts
- ✅ User Login/Register system
- ✅ Watchlist & Portfolio management
- ✅ Docker ready for production

### 🚀 How to Run
pip install -r requirements.txt
python app.py
# Open http://localhost:5000
